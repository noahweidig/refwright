# Find the <span class="rw-accent">PDF</span>.<br>Check, tag and <span class="rw-accent">file</span> it.

<p class="rw-hero__lede">refwright is one Zotero plugin that finds open-access PDFs, flags retracted papers, suggests tags and collections, and looks and feels like part of Zotero. No accounts, no analytics, no server, and AI is optional.</p>

[:lucide-rocket: Get started](getting-started.md){ .md-button .md-button--primary }
[:lucide-download: Download](https://github.com/noahweidig/refwright/releases/latest){ .md-button }

<div class="grid cards" markdown>

- :lucide-file-down:{ .lg .middle } **PDFs**

    ---

    Legal open-access sources in a fixed order. Wrong-paper PDFs are rejected before they are attached.

    [:lucide-arrow-right: Find PDFs](pdfs.md)

- :lucide-shield-alert:{ .lg .middle } **Retractions and citations**

    ---

    PubMed, Crossref and Retraction Watch. A read-only citation check against Crossref.

    [:lucide-arrow-right: Integrity checks](integrity.md)

- :lucide-tags:{ .lg .middle } **Tags**

    ---

    Free sources or any of 8 AI providers, with a review window, cleanup rules and learning from your edits.

    [:lucide-arrow-right: Tags](tags.md)

- :lucide-merge:{ .lg .middle } **Tag Manager**

    ---

    Find duplicate tags across the library, rename, merge or delete in bulk, and undo each change.

    [:lucide-arrow-right: Tag Manager](tag-manager.md)

- :lucide-folder-input:{ .lg .middle } **Collections**

    ---

    Ranked from the papers already in each collection. Offline by default, one-step undo.

    [:lucide-arrow-right: Collections](collections.md)

- :lucide-sparkles:{ .lg .middle } **Summaries and related items**

    ---

    One-paragraph summary notes, OpenAlex citation counts in a sortable column, and AI suggestions for related items.

    [:lucide-arrow-right: Summaries and related items](insights.md)

</div>
