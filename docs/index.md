# refwright

**Find the PDF, check it isn't retracted, tag it, file it.** One Zotero plugin, built to look and feel like part of Zotero. No accounts, no analytics, no server, and AI is optional.

[Get started :lucide-rocket:](getting-started.md){ .md-button .md-button--primary }
[View on GitHub :lucide-git-branch:](https://github.com/noahweidig/refwright){ .md-button }

<div class="grid cards" markdown>

- :lucide-file-down:{ .lg .middle } **[Find PDFs](pdfs.md)**

  ***

  Legal open-access sources in a fixed order. Wrong-paper PDFs are rejected before they are attached.

- :lucide-shield-alert:{ .lg .middle } **[Retractions and citations](integrity.md)**

  ***

  PubMed, Crossref and Retraction Watch. A read-only citation check against Crossref.

- :lucide-tags:{ .lg .middle } **[Tags](tags.md)**

  ***

  Free sources or any of 8 AI providers, with review, cleanup, learning and a Tag Manager.

- :lucide-folder-input:{ .lg .middle } **[Collections](collections.md)**

  ***

  Ranked from the papers already in each collection. Offline by default, one-step undo.

</div>
