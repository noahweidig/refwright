# refwright

One Zotero plugin for the chores around a paper. No accounts, no analytics, no server. AI is optional.

<div class="grid cards" markdown>

- :lucide-file-down: **[PDFs](pdfs.md)**

  Legal open-access sources in a fixed order. Wrong-paper PDFs are rejected.

- :lucide-shield-alert: **[Retractions and citations](integrity.md)**

  PubMed, Crossref and Retraction Watch. Read-only citation check.

- :lucide-tags: **[Tags](tags.md)**

  Free sources or any of 8 AI providers, with review, cleanup and a Tag Manager.

- :lucide-folder-input: **[Collections](collections.md)**

  Offline ranking from the papers already in each collection.

</div>
